CARLOS Racing Simulation — Android 13 PWA

WHAT'S INCLUDED
- Mobile-friendly top-down racing game
- Touch controls, keyboard controls, rival cars, laps, fuel, condition, cash, reputation, upgrades and repairs
- Offline cache after the first successful load
- Progress saved locally in the browser on the device

IMPORTANT
This ZIP is a Progressive Web App (PWA), not a signed APK. Android Chrome installs PWAs from a secure HTTPS website; it generally cannot install a PWA directly from a ZIP or file:// URL.

EASIEST INSTALL ROUTE (phone only)
1. Extract this ZIP.
2. Upload the contents of the CARLOS_Racing_PWA folder to a static HTTPS host such as GitHub Pages or Netlify.
3. Open the resulting HTTPS website in Chrome on Android 13.
4. Open Chrome's ⋮ menu and tap "Install app" or "Add to Home screen".
5. Confirm. CARLOS will appear as an app icon and can work offline after its first load.

No account or payment is needed to play the local game. Hosting provider terms may change.
